13. Mid-Semester Question Papers, Marking Scheme & Solutions
Mid-Term Assessment & Wireframing Exam Duration: 1.5 Hours • Max Marks: 30 • Weightage: Internal CIE
Q# Question & Bloom's Cognitive Depth CO Marks Model Answer & Evaluation Rubric Summary
Q1 Norman's 7 Stages of Action: Formulate and diagram Don Norman's Seven Stages of Action model. Analyze the Gulf of Execution and Gulf of Evaluation using an automated ATM cash withdrawal transaction. CO1 10 Rubric: Goal formation (2M), Execution stages: Intention, Action spec, Execution (4M), Evaluation stages: Perception, Interpretation, Comparison (4M). Exemplary answers bridge mental model gaps with feedback indicators.
Q2 Fitts's Law in UI Design: State Fitts's Law mathematical formulation: MT = a + b * log2(2D / W). Explain how target amplitude (D) and target width (W) dictate touch target sizing in responsive mobile interfaces. CO2 10 Rubric: Mathematical formulation & index of difficulty definition (3M), Application to screen edge pinning & infinite targets (4M), Minimum touch target guidelines (48x48dp) (3M).
Q3 Interactive Wireframe Architecture: Design a low-fidelity wireframe layout and user task flow for a campus room reservation system adhering to Nielsen's Usability Heuristics. CO3 10 Rubric: Clear task flow diagram (3M), Application of heuristic principles: Visibility of System Status & Error Prevention (4M), Annotation of UI controls and states (3M).

17. End-Semester Question Papers with Model Solutions & Marking Scheme
University Terminal Examination • Dec 2024 Duration: 3 Hours • Max Marks: 40 • Weightage: 40% External SEE
Q# Question Text & Cognitive Level CO Marks Marking Scheme & Model Solution Excerpt
Q1 Heuristic Evaluation vs Cognitive Walkthrough: Compare Heuristic Evaluation and Cognitive Walkthrough inspection methods. Detail Nielsen's heuristics for Error Prevention and Recognition over Recall with UI examples. CO1 12 Methodology comparison matrix (4M). Error prevention vs good error messages with input masking/date pickers (4M). Recognition vs recall with dropdown auto-complete vs command-line memory load (4M).
Q2 Activity-Centered vs User-Centered Design: Critically analyze Don Norman's Activity-Centered Design (ACD) paradigm versus classic User-Centered Design (UCD). In what contexts does ACD outperform UCD? CO2 14 Core definitions of tasks vs activities (4M). Analysis of complex tools (e.g. musical instruments, aircraft cockpits, coding IDEs) where activity constraints dominate individualized user preferences (6M). Comparative synthesis (4M).
Q3 Usability Metrics & System Usability Scale: Formulate the 10-item System Usability Scale (SUS) calculation method. Calculate the normalized score from a given raw survey response matrix and explain percentile interpretation. CO3 14 Odd item score subtraction (X-1) & even item score subtraction (5-X) (5M). Sum multiplied by 2.5 conversion factor (4M). Benchmark evaluation (SUS > 68 = above average, SUS > 80.3 = Grade A) (5M).
